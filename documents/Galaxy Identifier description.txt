Project: Galaxy-Identifier
Overview: Desktop application that performs object detection and segmentation on astronomical images to classify galaxy morphologies using a YOLO-based model trained on Galaxy Zoo dataset with custom data augmentation techniques including noise injection, padding, and image stitching to prevent overfitting and simulate real-world variations.
Tech Stack: Python 3.11, Ultralytics YOLO (v8/v11), PyTorch 2.7.1 with TorchVision 0.22.1, Kivy 2.3.1 for GUI, OpenCV 4.11.0 for image processing, Albumentations 1.4.24 for data augmentation, galaxy-datasets library for data loading, scikit-learn for train-test split, PIL for image handling.
Architecture: Modular pipeline with data preprocessing script converting Galaxy Zoo CSV labels to YOLO annotation format, augmentation module generating synthetic variations, YOLO training script using SGD optimizer with batch size 32 and image size 640x640, inference class wrapping YOLO model for detection, Kivy-based desktop app with tkinter file dialog for image input and real-time result display via NumPy array to PIL conversion. Containerized with Docker using Python 3.11-slim base image.
Challenges: Converting multi-label Galaxy Zoo classifications to single-class YOLO format, handling class imbalance in astronomical datasets, implementing custom augmentations without disrupting morphological features, integrating YOLO inference with Kivy UI event loop, managing memory for large image batches during training.
Outcomes: Achieved trained YOLO model for 8 galaxy morphology classes (smooth_round, unbarred_spiral, etc.), interactive application enabling user image upload and instant detection visualization, data augmentation increased training set diversity by synthetic generation techniques.
Keywords: galaxy morphology classification, YOLO object detection, astronomical image segmentation, data augmentation, Galaxy Zoo dataset, Kivy GUI, PyTorch training, OpenCV preprocessing, Docker containerization.
