Project: Image Colorization - CIFAR-10 Horse Classification

Overview:
Automated colorization of grayscale images using deep neural networks. Converts single-channel grayscale input to multi-channel color predictions via pixel-wise discrete color classification. Trained on 50,000 CIFAR-10 horse images (category 7), outputting per-pixel color category predictions that map to RGB values. Formulates colorization as supervised multi-class classification rather than regression.

Tech Stack:

PyTorch (nn.Sequential, nn.Conv2d, nn.ConvTranspose2d, nn.BatchNorm2d, nn.ReLU)
CIFAR-10 dataset (32×32 RGB images, 50K train / 10K test)
k-means color clustering (24 discrete color categories pre-computed)
NumPy for tensor manipulation
PIL for image I/O
CUDA GPU support
Adam optimizer (lr=0.001)
CrossEntropyLoss (multi-class pixel-wise classification)
Architecture:
Two comparable encoder-decoder designs:

PoolUpsampleNet: Conv2d (1→32→64 filters) + MaxPool2d stride-2 downsampling in encoder; Conv2d upsampling with nn.Upsample scale_factor=2 in decoder.
ConvTransposeNet: Conv2d (1→32→64) with stride=2 downsampling in encoder; ConvTranspose2d with stride=2, output_padding=1 for learnable upsampling in decoder.
Both: 32×32 input → bottleneck (64 filters at 8×8) → 32×32 output. BatchNorm after each conv layer. 5-block total depth. Input: 1-channel grayscale or 3-channel downsampled RGB. Output: 24-channel color category logits.

Challenges:

Discrete color representation requires post-hoc mapping of network output (argmax classification indices) to RGB values via k-means codebook lookup; loses color continuity across pixels
32×32 image resolution constrains spatial detail; stride-2 operations create 2×2 bottleneck
Pixel-wise classification with 24 categories at 1024 pixels per image = 24,576-way classification problem per batch; requires loss tensor reshaping to [batch×1024, 24] for CrossEntropyLoss compatibility
Small receptive field limits context for color consistency; stride-2 convolutions and upsampling must recover fine spatial detail
Outcomes:

Training loop: 25 epochs, batch_size=100, convergence tracking via train/validation loss and per-pixel accuracy
Model serialization via torch.save checkpoint support
Visualization pipeline generates per-epoch output PNG comparisons (grayscale input vs. ground-truth vs. predicted colorization)
Activation map extraction for debugging network layer responses
